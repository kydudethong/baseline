Court calibration

Click the four outer corners of the court, in the order listed. Click a placed point to drag it.
  1. Near-left corner (baseline nearest the camera, left side)
  2. Near-right corner
  3. Far-right corner (baseline furthest away)
  4. Far-left corner

If the far baseline is hidden behind the net, click where the net meets each sideline instead and tick half-court below.

Load a frame to begin.

Save as ml/configs/<name>_court.json, then run with
--set court.manual_points_path=configs/<name>_court.json
